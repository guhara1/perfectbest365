# 강남 가라오케 퍼펙트 (perfectbest365.com)

강남 논현동 프리미엄 가라오케 라운지 **퍼펙트**의 공식 웹사이트입니다.
순수 정적(HTML/CSS/JS) 사이트로, 별도 빌드 과정 없이 바로 배포할 수 있습니다.

## 비즈니스 정보
- **상호:** 강남 가라오케 퍼펙트
- **주소:** 서울특별시 강남구 논현로 645 (논현동 152) 엘리에나호텔 B1·B2
- **전화:** 010-3460-8953
- **운영 시간:** 매일 18:00 – 05:00

## 페이지 구성
| 파일 | 메뉴 | 내용 |
| --- | --- | --- |
| `index.html` | 홈 | 히어로, 소개, 대표 서비스, 가격 요약, 위치, 후기, FAQ |
| `about.html` | 소개 | 브랜드 스토리, 차별화 포인트, 비전 & 미션, 연혁 & 수상 |
| `facilities.html` | 시설 & 서비스 | 객실 타입, 음향 & 조명, 주류 & 안주, 부가 서비스, 위생 |
| `pricing.html` | 가격 & 패키지 | 시간별 요금, 이벤트 패키지, 단체 할인, 환불 규정, 가격 FAQ |
| `reservation.html` | 예약 & 오시는 길 | 예약 방법, 온라인 예약 폼, 위치 & 교통, 주차 정보 |
| `support.html` | 고객센터 | 공지사항, FAQ, 1:1 문의, 개인정보처리방침, 이용약관 |

## 디렉터리
```
.
├── index.html
├── about.html
├── facilities.html
├── pricing.html
├── reservation.html
├── support.html
├── css/style.css      # 공통 스타일 (다크 & 골드, 모바일 우선 반응형)
├── js/main.js         # 모바일 메뉴, FAQ 아코디언, 폼 처리
├── images/            # 이미지 에셋
├── robots.txt
└── sitemap.xml
```

## 주요 기능
- 모바일 우선 반응형 디자인 (CSS Grid/Flex, 햄버거 메뉴, 하위 메뉴 아코디언)
- 상단 메뉴 + 드롭다운 하위 메뉴 (데스크톱 hover / 모바일 토글)
- FAQ 아코디언, 예약·문의 폼 (데모 — 백엔드 연동 시 동작)
- `LocalBusiness`(NightClub) 스키마 마크업, 페이지별 고유 메타 타이틀/설명
- Google 가이드라인 준수: 정확한 사업장 정보, 모바일 친화, 유용한 콘텐츠

## 로컬 실행
정적 파일이므로 파일을 그대로 열거나 간단한 서버로 확인할 수 있습니다.
```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```
